# Context Base - setup prompt

The entry rung. Paste the block below into any frontier model (Claude, ChatGPT, Gemini, or Cowork). Answer the four lines, and it stands up a context base for one area of your work: it proposes your folders, writes your root map, and gives you a retrieval prompt to use from then on. It runs in your own account; nothing leaves it.

It goes faster if you talk instead of type, and it works as a group exercise with one person at the keyboard.

```
I'm setting up a private context base: a folder of plain files my AI
can reason over for one area of my work. Help me stand it up.

ABOUT ME AND THE AREA
- My role: [e.g. head of strategy at a mid-size retailer]
- The one area this base is for: [e.g. our annual strategy + its decisions]
- What I keep re-explaining to my AI every time: [1-3 things]
- Who uses it: [just me / my team / one project]

YOUR TASK
1. Propose 4-6 folders that mirror how this area is actually organised,
   not a generic taxonomy. Name each and say in one line what lives in it
   and the kind of file it holds (a decision, a note, a signal). Include
   one dated intake folder where new material lands, so the base compounds
   instead of scattering.
2. Write the root map: a one-page CONTEXT.md that tells any model what
   this base is, who I am, what each folder holds, and how to navigate it.
   Write it so a model reads it first and knows where to look.
3. Give me one retrieval prompt I paste at the start of a session to point
   my AI at this base and have it answer from the files, naming which file
   each answer came from.
4. Name the single weekly maintenance step that keeps this base honest, in
   one line.

CONSTRAINTS
Plain files and folders only. No vector database, no embeddings, no new
platform. If a folder you propose would rarely be opened, drop it. Keep
the root map under one page. Be specific to my area: if your folders
could apply to any company, redo them. If my four answers above are
ambiguous, ask me up to 3 questions before proposing anything.
```

## After it answers

1. Create the folders it proposed, on your own drive.
2. Save its `CONTEXT.md` as the file at the root of the base.
3. Drop in one real file to set the shape (a decision, a note). See `starter/` for a worked example.
4. Keep the retrieval prompt it gave you; paste it at the start of a session when you want the AI to answer from the base.
5. Put a recurring twenty-minute review in your calendar, and use `weekly-maintenance.skill.md` to run it.
